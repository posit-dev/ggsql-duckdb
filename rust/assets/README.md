# Vendored hep viewer assets

These files are served by the extension's in-process HTTP server (and inlined
into self-contained HTML output) so plots render offline (no CDN fetches).
They are baked into the extension binary via `include_str!` in
`rust/src/server.rs`.

| File | What | Provenance |
|---|---|---|
| `hep-viewer.js` | IIFE viewer bundle (`window.ggsqlRenderHep`) | Built by `tools/hep-viewer/build.mjs` from `tools/hep-viewer/entry.js` + the `hephaestus-svg-wasm` ES module |
| `hep-assets.js` | Sets `globalThis.ggsqlHepAssets`: wasm binary + four Roboto faces, gzip+base64 | Generated by `tools/hep-viewer/build.mjs` from the `hephaestus-svg-wasm` npm package |
| `app.html` | SPA shell served at `/` (polling, history, heartbeat) | Hand-written |

## Upgrading

The `hephaestus-svg-wasm` npm version **must track the hephaestus crate the
ggsql dependency links** — the .hep document format version is compared for
equality at load time, so a mismatch fails loudly, not subtly. To upgrade:

```sh
cd tools/hep-viewer
npm install hephaestus-svg-wasm@<version>
npm run build
```

and commit the regenerated `hep-viewer.js` / `hep-assets.js`.

hephaestus-svg-wasm is MIT licensed; the bundled Roboto faces are OFL-1.1
(`fonts/OFL-Roboto.txt` in the npm package).
